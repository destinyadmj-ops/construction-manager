# scripts

このディレクトリのスクリプトの使い方をまとめます。

## git-push-safe.ps1

目的:
- ローカルで変更をステージ・コミットし、`git pull --rebase origin <branch>` を実行してから `git push origin <branch>` を行うことで、リモートとの競合を減らす短いヘルパースクリプトです。

使用方法:
1. PowerShell を開く（必要に応じて管理者権限ではなく通常で良い）。
2. リポジトリルートで次を実行:

```powershell
.\scripts\git-push-safe.ps1 -Message "your commit message"
```

説明:
- ブランチ名は現在のチェックアウト中のブランチを自動検出します。
- 変更をすべてステージし、差分がある場合はコミットします。コミットメッセージを `-Message` で指定します（省略時は `WIP: quick update`）。
- `git pull --rebase origin <branch>` を実行してローカルのコミットをリモートの先頭にリベースします。コンフリクトが発生した場合はリベースを中止し、手動で解決するよう促します。
- リベースに成功したら `git push origin <branch>` を実行します。

注意:
- 複雑なマージコンフリクトや非標準のリモート設定がある場合は、このスクリプトを使わず手動で操作してください。
- CIやリポジトリのブランチ保護ルールによっては直接プッシュが制限される場合があります。その場合は PR を作成してください。
