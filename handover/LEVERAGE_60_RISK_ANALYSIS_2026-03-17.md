## レバレッジ 60 でのリスク計算

### 前提条件
- 現在の ACCOUNT_BALANCE: 1,000 USDT
- 現在の RISK_PER_TRADE: 2% (20 USDT/トレード)
- トレーリングストップ: 2% (逆指値までの価格変動幅)
- 想定 BTCUSDT 価格: 100,000 USDT

### 計算式

#### 1. 必要証拠金（Bitget hedge mode）
```
必要証拠金 = (ポジションサイズ × エントリー価格) / レバレッジ
必要証拠金 = (size × 100,000) / 60
```

例: size = 0.01 BTC の場合
```
証拠金 = (0.01 × 100,000) / 60 = 1,000 / 60 ≈ 16.67 USDT
```

#### 2. 1トレード最大損失額（固定）
```
最大損失 = ACCOUNT_BALANCE × RISK_PER_TRADE
最大損失 = 1,000 × 0.02 = 20 USDT
```

#### 3. 許容ポジションサイズ（SL 2% 時）
```
逆指値までの価格変動額 = エントリー価格 × 2% = 100,000 × 0.02 = 2,000 USDT

許容サイズ = 最大損失 / (価格変動額/単位)
許容サイズ = 20 / (エントリー価格 × 0.02)
許容サイズ = 20 / (100,000 × 0.02)
許容サイズ = 20 / 2,000 = 0.01 BTC
```

#### 4. 証拠金使用率（レバレッジ 60 時）
```
証拠金使用率 = (0.01 × 100,000 / 60) / 1,000
証拠金使用率 = 16.67 / 1,000 ≈ 1.67%

つまり：全口座の 1.67% の証拠金で 0.01 BTC を建てられる
```

## ロスカット計算（重要）

### ロスカット価格の式

```
ロスカット価格 = エントリー価格 × (1 - 1/レバレッジ)

レバレッジ 30:
  LC = 100,000 × (1 - 1/30) = 100,000 × 0.9667 = 96,670
  → 3.33% の下落で ロスカット

レバレッジ 60:
  LC = 100,000 × (1 - 1/60) = 100,000 × 0.9833 = 98,330
  → 1.67% の下落で ロスカット
```

### 実例: BTCUSDT 100,000 エントリー

| レバレッジ | SL価格 | ロスカット価格 | 安全幅 | リスク評価 |
|----------|-------|-------------|-------|----------|
| 30 | 98,000 | 96,670 | 1,330 | ✓ 中程度 |
| **60** | **98,000** | **98,330** | **-330** | ❌ **SL超える可能性** |

**⚠️ 警告: レバレッジ 60 + SL 2% の場合、SL が発動する前にロスカットされる可能性がある！**
